# 부산 시민 AI 체험의 날

행사 홍보 웹페이지입니다. HTML과 CSS는 `event_homepage.html`에 함께 작성되어 있습니다.

## 웹페이지

https://edu21-cloud.github.io/busan-event-webpage/

- `index.html`: 행사 웹페이지로 연결하는 기본 진입 파일
- `event_homepage.html`: 행사 홍보 웹페이지 원본
- `data/busan_official_logo_ko.png`: 부산광역시 공식 로고
- `.nojekyll`: 정적 파일 배포 설정

GitHub Pages는 `main` 브랜치의 루트 폴더에서 배포합니다. 웹페이지 수정 후 변경 파일을 `main`에 커밋하고 푸시하면 다시 배포됩니다.

행사 정보는 사용자 제공 기획 내용을 기준으로 작성합니다.
